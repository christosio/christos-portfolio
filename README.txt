Christos Ioannides — accessible portfolio redesign

Extract this ZIP into the document root of christosio.uk (often public_html). index.html, img/ and cv/ must all be directly beside each other there. The page contains its styles and script directly to avoid older server files being loaded. Do not leave them inside an extra portfolio-accessible/ folder. Open index.html locally to preview. No build tools are needed. After upload, hard refresh with Ctrl+F5. If the old layout remains, check that the new index.html actually replaced the one your domain serves.

Contact buttons use the Messenger and LinkedIn destinations from your original website. The original contact form had no submission endpoint, so this version uses working contact links. The Work section has been removed until there are specific projects to show.

Review the education details, CV, and Astana and Pilsen text before publishing. Those details came from the supplied ZIP. Google Fonts are optional; system fallbacks render if offline.
